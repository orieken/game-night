# Mockup Specifications

## Overview
Four distinct design concepts for the Game Night Tracker application, each with unique aesthetic and UX focus.

---

## Mockup 1: Board Game Café Aesthetic

### Theme
Warm, inviting, tactile - capturing the cozy atmosphere of a board game café.

### Color Palette
```
Primary: #8B4513 (Saddle Brown)
Secondary: #DEB887 (Burlywood)
Accent: #2F4F2F (Dark Olive Green)
Highlight: #FFD700 (Gold)
Background: #FAF0E6 (Linen)
Text: #3E2723 (Dark Brown)
```

### Typography
- **Headings**: Playfair Display (Serif) - adds elegance
- **Body**: Lato (Sans-serif) - readable and friendly
- **Accents**: Courier New (Monospace) - for scores/stats

### Visual Elements

#### Cards
- Physical game box feel with subtle shadows
- Rounded corners (8px border radius)
- Textured backgrounds (wood grain, fabric)
- Stamped/embossed effects for headers

#### Icons
- Illustrated game pieces: meeples, dice, cards, tokens
- Hand-drawn style illustrations
- Vintage board game aesthetic

#### Leaderboard
- Trophy cabinet style display
- Physical medal imagery (gold, silver, bronze)
- Wooden plaques for rankings
- Vintage ribbon banners

#### Achievements
- Badge system like vintage merit badges
- Illustrated icons with retro color palette
- Pin/button aesthetic

#### Photos & Media
- Polaroid-style photo frames
- Scrapbook-style layouts
- Handwritten-style labels

### Key Screens

#### Dashboard

```
│  │Friday │ │Sat    │ │Sunday │    │

├─────────────────────────────────────┤
│  Recent Activity                    │
│  📸 [Polaroid-style photos]         │
└─────────────────────────────────────┘
```

#### Leaderboard

```
│       🏆 CHAMPIONS BOARD 🏆         │
```

- **All Text**: Inter or Poppins (Modern Sans-serif)
- **Monospace**: JetBrains Mono (for stats/numbers)

### Visual Elements

- Glassmorphism effect (semi-transparent with blur)
- Subtle shadows and hover effects
- Clean white backgrounds
- Minimal borders

- Line charts for performance over time

- Subtle animations on interaction

### Color Palette
```

Secondary: #4ECDC4 (Teal)

Highlight: #A8E6CF (Mint Green)
Background: #2D3436 (Dark Gray)
Background Alt: #FFFFFF (White)
Text: #2D3436 (Dark Gray)
```

### Typography
- **Headings**: Fredoka One or Righteous (Bold, Rounded)
- **Body**: Nunito (Friendly Sans-serif)
- **Stats**: Orbitron (Futuristic)

### Visual Elements

#### Character Avatars
- RPG-style character portraits
- Level indicators
- XP bars below avatars
- Class badges (e.g., "Strategy Master", "Party Guru")

#### Progress Systems
- Animated XP bars
- Level-up animations
- Skill trees
- Achievement unlock animations (confetti, sparkles)

#### Quest Board
- Challenges displayed as quests
- Difficulty indicators (⭐⭐⭐)
- Reward previews
- "Accept Quest" buttons

#### Badges & Achievements
- Pixel art or illustrated designs
- Shiny/glowing effects for rare achievements
- Collection display (showcase unlocked badges)

#### Battle/Duel Interface
- Head-to-head matchup displays
- VS. graphics
- Win/loss records
- Challenge buttons

## Recommended Implementation Strategy

### Phase 1: Choose Primary Mockup
Evaluate based on:
1. Target audience preferences
2. Development timeline
3. Technical complexity
4. Unique value proposition

### Phase 2: Hybrid Approach (Optional)
Consider combining elements:
- **Example 1**: Mockup 2 structure + Mockup 3 gamification
- **Example 2**: Mockup 4 social features + Mockup 1 aesthetics

### Phase 3: Progressive Enhancement
Start with core mockup, add features from others:
1. Launch with primary design
2. A/B test alternative elements
3. Iterate based on user feedback
